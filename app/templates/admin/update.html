To replace its own container, the app needs to be able to talk to Docker. Add the socket as a volume mapping and restart the container — once, from Unraid, and never again.

Unraid → Docker → NAL → Edit → Add another Path

Name:       Docker Socket
Container:  {{ socket_path }}
Host:       {{ socket_path }}
Access:     Read/Write

Or in docker-compose.yml

volumes:
  - ./data:/app/data
  - {{ socket_path }}:{{ socket_path }}
{% endif %}

Worth knowing before you do: anything that can reach the Docker socket can control Docker on the host, which is as good as root. That is the price of a container being able to replace itself, and it is why this is off unless you turn it on. Only admins can reach this page, and the image it will pull is fixed in code — you choose a version, never an image.

Want to try an unmerged branch before merging it?

Pull requests are built and tested by CI but deliberately not published — every push to every branch would be another image in the registry, and most are never installed. So a branch build is published only when you ask for one:

  1. Open the Publish Docker Image workflow on GitHub.
  2. Run workflow → pick the pull request's branch.
  3. Put pr-number in the tag box — then it shows up here named after the pull request.
  4. Wait for the build, hit Refresh list, and install it.

It publishes one image and leaves latest alone, so the rest of the league is unaffected until you install it. To go back, install latest again.
